# Code Review Skill

审查 Python 代码时，重点检查以下高频低级错误：

1. 函数定义多余冒号（`def f(): ->`）
2. 函数体顶格/缩进错乱
3. 误用循环外变量
4. 将 `@tool` 装饰对象当普通函数直接调用（须用 `.invoke()`）
5. 模块路径/文件名大小写不匹配
6. 跨模块顶层导入导致的循环依赖（改用函数内延迟 import）
7. 未定义变量、未实现函数被导入

输出格式：按严重度列出问题位置与修复建议，若无问题则明确说明。
